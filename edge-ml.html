The problem and purpose

Drowsiness reduces a driver’s attention and reaction time, which makes it a serious road-safety risk. This project explores whether a camera can detect signs of drowsiness in real time by analyzing facial landmarks in video frames.

The stack includes TensorFlow Lite, which is designed for on-device inference, so latency matters. The project’s work on the inference pipeline targets that goal.

Limitations and possible next steps

  • This page was built without opening the repository, so confirm the workflow and techniques before presenting them in interviews.
  • The dashboard uses synthetic signals, not camera input or real drivers.
  • Landmark-based systems commonly struggle with lighting changes, head pose, glasses and partial occlusion. These should be tested.
  • Possible next steps: calibrate thresholds on labeled footage, benchmark latency on the target device, and log alert events.
